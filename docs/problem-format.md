# Маселелерди импорттоо форматы (JSON)

Маселелерди массалык түрдө эки жол менен кошсо болот:

1. **Админ панели → Импорт**: JSON файлды тандаңыз же текстти коюңуз. Адегенде «Текшерүү» баскычы менен маалыматты базага жазбай текшерип алсаңыз болот.
2. **Буйрук сабы:**

   ```bash
   npm run problems:import -w backend -- --file ../docs/problems.example.json --dry-run
   npm run problems:import -w backend -- --file ../docs/problems.example.json --status PUBLISHED
   ```

   `--dry-run` — эч нерсе жазбай текшерет. `--status` — өз `status` талаасы жок маселелерге колдонулат. `--author <email>` — автор (демейки: биринчи админ).

Толук мисал: [`problems.example.json`](problems.example.json).

## Файлдын түзүлүшү

Файлда маселелердин массиви `[...]` же `{ "problems": [...] }` объекти болот. Бир жолу эң көп 500 маселе импорттолот.

## Маселенин талаалары

| Талаа                         | Милдеттүүбү               | Сүрөттөмө                                                                                                                                |
| ----------------------------- | ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `slug`                        | жок                       | Шилтеме аты: `a-z`, `0-9`, `-`. Мындай slug'у бар маселе базада болсо, ал **жаңыртылат**. Берилбесе, аталыштан автоматтык түрдө түзүлөт. |
| `status`                      | жок                       | `DRAFT` (демейки), `PUBLISHED` же `ARCHIVED`.                                                                                            |
| `subjectSlug`                 | ооба                      | `math`, `physics`, `informatics` (же админ кошкон предмет).                                                                              |
| `topicSlug`                   | ооба                      | Ошол предметтин темасы, мисалы `algebra`, `geometry`, `kinematics`.                                                                      |
| `titleKy` / `titleRu`         | ky — ооба                 | Аталышы, 3–200 белги.                                                                                                                    |
| `statementKy` / `statementRu` | ky — ооба                 | Шарты, 10–10 000 белги.                                                                                                                  |
| `answerType`                  | ооба                      | `INTEGER`, `DECIMAL`, `TEXT`, `MULTIPLE_CHOICE`.                                                                                         |
| `correctAnswer`               | ооба                      | Туура жооп (төмөндү караңыз). Окуучуларга **эч качан** көрсөтүлбөйт.                                                                     |
| `tolerance`                   | DECIMAL үчүн ооба         | Жол берилген ката, мисалы `0.01`.                                                                                                        |
| `choices`                     | MULTIPLE_CHOICE үчүн ооба | 2–6 вариант: `{ "id": "a", "textKy": "...", "textRu": "..." }`. `id` — бир латын тамгасы.                                                |
| `solutionKy` / `solutionRu`   | ky — ооба                 | Чечими.                                                                                                                                  |
| `hintKy` / `hintRu`           | жок                       | Кеңеш.                                                                                                                                   |
| `difficulty`                  | ооба                      | 1–5.                                                                                                                                     |
| `olympiadLevel`               | ооба                      | `SCHOOL`, `DISTRICT`, `REGION`, `NATIONAL`, `INTERNATIONAL`.                                                                             |
| `gradeFrom` / `gradeTo`       | ооба                      | 7–11, `gradeTo ≥ gradeFrom`.                                                                                                             |
| `points`                      | жок                       | Негизги упай, 1–100 (демейки 10). Чыныгы упай = `points × кыйындык коэффициенти`.                                                        |
| `source`                      | жок                       | Булагы, мисалы «Республикалык олимпиада 2023».                                                                                           |

## Жооптун түрлөрү

- **INTEGER** — `"correctAnswer": "70"`. Окуучунун жообундагы боштуктар, `+` жана алдыңкы нөлдөр эске алынбайт.
- **DECIMAL** — `"correctAnswer": "3.14"`, `"tolerance": 0.01`. Окуучу `3,14` же `3.14` деп жаза алат.
- **TEXT** — бир же бир нече туура вариант: `"correctAnswer": ["17", "17_8"]`. Чоң-кичине тамга жана боштуктар эске алынбайт.
- **MULTIPLE_CHOICE** — туура варианттын `id`'си: `"correctAnswer": "b"`.

## Формулалар жана код

- Сапта: `$x^2 + 1$`, өзүнчө блокто: `$$\dfrac{a}{b}$$` (KaTeX).
- JSON'до тескери сызыкты эки жолу жазыңыз: `"$\\dfrac{1}{2}$"`.
- Ондук үтүр формулада: `$1{,}5$`.
- Бирдиктерди формуладан тышкары жазыңыз: `$10$ м/с²`.
- Программа коду үчүн: ` ```python ... ``` `.
- Жөнөкөй доллар белгиси керек болсо: `\\$`.

## Текшерүү жана каталар

Ар бир маселе өзүнчө текшерилет. Катасы барлары импорттолбойт, калгандары сакталат. Отчетто ар бир каталуу маселенин номери, талаасы жана ката билдирүүсү көрсөтүлөт.
